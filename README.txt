SOVEREIGN BODY - GITHUB PAGES HERO

Files:
  index.html
  styles.css
  assets/runner-man.webp
  assets/runner-woman.webp

Upload index.html and styles.css to the root of the existing GitHub Pages repository.
Upload the two .webp images into an assets/ folder.
You do NOT need to change GoDaddy DNS, the custom domain, GitHub Pages settings, or Zoho mail records.

The two images fade automatically every 14 seconds using CSS.
Users who choose reduced motion see the man image without animation.

To use a static background instead of the alternating images:
Remove the .hero-image--woman div from index.html.
You may then remove the .hero-image--woman and @keyframes rules from styles.css.

To keep your existing HTML instead of replacing it, adapt only the hero markup and CSS rather than uploading the entire index.html.
